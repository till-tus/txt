# Security Policy

## Supported Versions

Text Launcher is pre-1.0. Security fixes will target the current `main` branch unless release branches are introduced later.

## Reporting a Vulnerability

Please do not open a public issue with vulnerability details.

If GitHub private vulnerability reporting is enabled for the repository, use that. Otherwise, contact a maintainer privately. If no private contact is listed yet, open a minimal public issue asking for a private security contact and do not include exploit steps, sensitive logs, or proof-of-concept details.

Please include:

- Affected version or commit.
- Device and Android version, if relevant.
- A clear description of the issue.
- Steps to reproduce.
- Potential impact.
- Any suggested fix, if you have one.

## Security Expectations

Text Launcher is local-first and should avoid collecting or transmitting user data. Changes that touch permissions, app usage data, calendar data, notes, backups, exported components, accessibility services, package uninstall flows, package removal receivers, or file handling should receive extra review.

## Disclosure

Maintainers will aim to acknowledge reports promptly, investigate in good faith, and coordinate public disclosure after a fix or mitigation is available.
