# Code of Conduct

## Our Pledge

We want Text Launcher to be a welcoming project for people with different backgrounds, identities, experience levels, and perspectives. Everyone participating in this project is expected to help keep the space respectful, constructive, and focused on the work.

## Expected Behavior

- Be kind, patient, and direct.
- Assume good intent while still naming problems clearly.
- Give feedback about ideas, code, and behavior rather than personal traits.
- Respect differing needs, constraints, and communication styles.
- Help newcomers understand project norms without condescension.

## Unacceptable Behavior

- Harassment, threats, insults, or sustained disruption.
- Sexualized language or attention.
- Discriminatory comments or exclusionary behavior.
- Publishing private information without explicit permission.
- Bad-faith reporting, trolling, or repeated boundary-pushing.

## Enforcement

Maintainers may remove comments, close issues, reject pull requests, or restrict participation when behavior harms the project or its contributors. Responses should be proportionate to the impact and pattern of the behavior.

If you experience or witness unacceptable behavior, contact a maintainer privately. If no private contact is available yet, open a minimal issue asking for a private reporting channel without including sensitive details.

## Scope

This code of conduct applies in project spaces such as issues, pull requests, discussions, chats, and any public context where someone is representing the project.
